1*1卷积核：实现款通道的交互和信息整合
        卷积核通道数的降维和升维，减少网络参数
全局平均池化（GPA)：把28*28*2，长宽28通道数为1的特征图每一个通道取平均值，再进行展平
            这样可以减少模型参数，抑制过拟合，使得特征图的输入尺寸更灵活
            缺点：使特征图信息丢失，使得梯度反向传播更难
